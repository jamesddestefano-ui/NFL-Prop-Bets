## Proposed scorecard: a dashboard, not a single reputation number

MODEL ASSUMPTION / UNTESTED HYPOTHESIS. Retain accountability's current fields and add the following research-only definitions for review. A future implementation can map these to the existing schema; this report creates no competing authoritative ledger.

Observation population: predeclare a bounded watchlist, NFL prop categories, collection windows, quote providers and detection cadence. Preserve collection outages. Define N_posts as all captured posts; N_eligible as unique actionable original NFL-prop recommendations with enough contract identity, including passes and failed verifications where relevant. Report incomplete recommendations separately. Do not interpret unavailable feed coverage as zero recommendations. Record author edits/deletions only when actually observed; preserve versions.

Identity and dependence: retain original permalink, post ID, original posted time, first observed time, author, cited upstream source/model, shared screenshots, links and dependency-thesis IDs. Link account-level commercial affiliations separately from tip-level evidence clusters. Tag FIRST_MOVER, INDEPENDENT_CONFIRMATION, FOLLOWER, REPOST, UNCLEAR. Multiple independent derivations can concern the same contract; use a separate contract key, attribution key and thesis cluster rather than deduplicating all identical picks or treating every new permalink as independent. Record confidence/evidence for cluster joins; audit uncertain clusters under merged and separated sensitivity analyses.

Quote provenance levels (not replacement Market Truth grades): Q0 analyst claim only; Q1 archived third-party screen; Q2 independent current named-book display with timestamp and rules; Q3 documented user-authorized accepted fill with exact price and stake. Q2 does not prove acceptance or available capacity; never place a bet to test it. Record jurisdiction, personalization/promotion restrictions and limit information only where known and permitted, keeping private account data unpublished.

Metrics and denominators:
- Quote-verification coverage = N_independently_verified / N_eligible. Also report attempts/eligible, failures/attempts and unavailable/eligible; missingness reasons distinguish absent quote, expired price, inaccessible book and contradictory contract.
- Stale-at-detection rate = N_confirmed_stale / N_with_detection_quote. Report N_unknown / N_eligible alongside it. Never count unknown as executable or stale.
- Actionable-at-detection rate = N_verified_still_within_precommitted_play_to / N_eligible; call unresolved cases unresolved, and report conditional rate among verifiable cases too. This is a workflow yield, not profitability.
- Attribution coverage = N_tips_with_resolved_origin / N_eligible. Report raw tip count, unique contract count, upstream cluster count and game/week count together.
- Pre-move discovery rate = N_definitely_before_verified_favorable_move / N_tips_with_sufficient_prepost_quotes. Also show that denominator divided by N_eligible; no-move, ambiguous-order and insufficient-observation categories separately.
- Median lead minutes is conditional on observed qualifying moves. Quote sampling produces interval-censored movement times: if last unchanged quote L and first changed quote U, movement time lies in (L,U], so lead lies in (L-post,U-post]. If interval crosses zero, temporal precedence is unresolved. Timestamp granularity/clock offsets widen the interval; they do not establish an exact first mover.
- CLV coverage = N_same_contract_matched_close / N_eligible. Mean/median CLV and positive rate use only matched observations, with missingness explicit. Keep LINE_CLV and PRICE_CLV separate. Different thresholds need an identified distribution or same-threshold alternate close; otherwise COMBINED_CLV unavailable.
- Source flat-stake hypothetical ROI = total verified hypothetical net returns / verified risked units, with pushes/voids distinct and all settlement counts shown. Source-stated ROI is a separate claim. User tickets and actual realized P/L remain separate.
- Brier only on explicitly precommitted probability forecasts with correct settlement basis. No probability inferred from confidence adjectives, prices or model means. For push-excluded binary scoring, require conditional non-push probability; alternatively score the complete outcome vector with a declared multiclass convention. Include calibration counts, uncertainty and scoring coverage.

Uncertainty: game/week dependence reduces independent evidence. Predeclare game/week-block resampling or a specified hierarchical analysis and report cluster count; do not apply independent Bernoulli intervals mechanically to duplicated tips. With too few clusters, descriptive results only. Any complete-case ranking also needs missingness sensitivity: sources with unavailable poor prices cannot silently receive higher ratings.
